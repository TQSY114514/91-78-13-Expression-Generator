# 917813 Expression Generator (Numeric Proof)

一个基于 **91、78、13** 三个原子数字的特殊算术多项式与表达式逆向生成器。

该项目提供了一个具有古典魔法美学的桌面交互界面（Grimoire 风格），能够将输入的任意正整数，逆向拆解并重构为仅由数字 `91`、`78`、`13` 及其视觉切分片段组成的等价算术多项式。

---

## 🌟 核心特性 (Features)

* **视觉序列还原**：算法优先搜索去掉符号后能序列化还原为 `91`、`78`、`13` 的表达式（如输入 `909` 会被拆解为包含 `9178` 视觉序列的 `(917-8)`）。
* **严格视觉原子性**：运算过程中使用的数字均源自完整的 `91`、`78`、`13` 序列拆解（有 `7` 必有 `8`），杜绝非法数字切片。
* **严格层级括号系统**：根据递归深度严格应用 `()` $\rightarrow$ `[]` $\rightarrow$ `{}` 的向内嵌套秩序，视觉层级清晰无乱套。
* **绝对收敛与保底机制**：引入双重有效性校验（拦截结尾残留运算符），配合 $n = (n-1) + 1$ 的保底逻辑，确保任何非负整数都能生成完整闭合的数学算式。
* **动态流体 UI**：基于 Tkinter 实现无边框拖拽、窗口大小根据算式长度自适应伸缩、屏幕边缘智能吸附收回以及淡入打字机特效。

---

## 🧠 算法原理 (Algorithm)

项目的核心算法类 `FinalArtAlgo` 采用了**算术语法树搜索 + 递归降维**的混合策略：

1. **原子基底 (Atoms)**：定义核心序列 `["91", "78", "13"]`。
2. **策略 A - 视觉切分碰撞 (Visual Split Search)**：从原子拼接成的随机池中寻找一次切割并插入四则运算符，若匹配目标值则直接生成顶层表达式。
3. **策略 B - 递归基数分解 (Recursive Reduction)**：使用 `91`、`78`、`13` 作为基数对大数进行除法求余分解，递归求解商与余数。
4. **策略 C - 终极保底 (Fallback Protection)**：当无法直连或降维时，将数字拆解为 $(n-1) + 1$，其中 `1` 被固定论证为原子表达式 `((91-78)/13)`。

## 🚀 快速开始 (Quick Start)

1. 克隆或下载本仓库代码：
```bash
git clone https://github.com/your-username/917813-Expression-Generator.git
cd 917813-Expression-Generator

```


2. 运行主程序：
```bash
python main.py

```


3. **操作指南**：
* 在中央输入框中输入任意数字。
* 观察中间等号旋转并自动生成论证算式。
* 按住鼠标左键可自由拖动无边框窗口。
* 按 `Esc` 键退出程序。
